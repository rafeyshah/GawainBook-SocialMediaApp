# Sample reader avatars

`sample-*.png` are generated with DiceBear's **Lorelei** style
(https://www.dicebear.com/styles/lorelei), a design by Lisa Wischofsky licensed
**CC0 1.0** (public domain dedication). No attribution is required; this note
records where they came from. Generated 12 Nov 2026 with:

    https://api.dicebear.com/9.x/lorelei/png?seed=<username>&size=256

The other photos in this folder came with the original template and their
licence is unknown, so they are not used by the demo data.
